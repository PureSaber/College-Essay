# 策展方法与证据标准

最后更新：2026-08-29

## 1. “高分”在本仓库中的含义

大多数港新大学不公开个人陈述或短答的单项分数。因此，本仓库不声称某篇公开材料获得了学校意义上的“满分”或“高分”。

`quality_score` 是 **0–100 的策展优先级**，只回答一个问题：这条公开材料有多值得申请者花时间阅读和拆解？

评分维度：

| 维度 | 权重 | 关注点 |
|---|---:|---|
| 结果与身份可核验性 | 30 | 是否明确说明录取、奖学金、项目和年份；是否有较可信的一手叙述 |
| 文书细节 | 25 | 是否披露题目、结构、主题、修改过程或接近原文的材料 |
| 教学价值 | 20 | 是否能提炼成可复用的写作原则，而不是只讲“做自己” |
| 结果强度 | 15 | 直接录取、竞争性项目、全额奖学金等只作为辅助信号 |
| 路径与时效 | 10 | 是否标明国际/本地、JUPAS/Non-JUPAS/ABA、项目和申请年份 |

**结果强不等于文书强。** 成绩、竞赛、课程匹配、推荐信、面试和名额都会影响录取；奖学金结果也不能证明文书是决定性因素。

## 2. 证据等级

| 等级 | 定义 | 使用方式 |
|---|---|---|
| A | 学校官方展示，或作者本人授权且录取结果可核验 | 可列为强证据 |
| B+ | 一手公开叙述，明确录取/奖学金，并披露较多文书细节 | 重点案例 |
| B | 一手公开叙述，明确录取，并披露部分文书思路 | 可重点参考 |
| C+ / C | 匿名自述、只有结果没有文书细节，或结果证据有限 | 作为线索，不作结论 |
| D+ / D | 未核验视频、营销样本或无法确认录取结果 | 只保留导航或排除 |

`featured=true` 只允许用于 `admitted_case`，且通常要求分数不低于 85、证据等级至少为 B。

## 3. 收录与排除

收录：

- 学校官网的当年申请要求；
- 录取者本人公开的申请经验；
- 能说明题目、结构、修改逻辑或材料分工的案例；
- 明确标注年份、路径和局限的社区经验；
- 有授权或开放许可证的作者投稿全文。

排除或降级：

- 无原始链接的“内部高分范文”；
- 培训机构把普通模板包装成“招生官满分文书”；
- 无法确认学校、项目、年份或录取结果的截图；
- 含大量个人敏感信息且未脱敏的材料；
- 付费盗版、网盘泄露或未经作者许可的整篇转载；
- 只凭奖学金结果推断“文书一定优秀”的材料。

## 4. 版权规则

第三方来源默认采用 `link_and_original_analysis_only`：

1. 仓库不镜像第三方完整文书；
2. 只保存事实元数据、中文转述、结构拆解和原始链接；
3. 来源下架后，默认保留“已失效”状态，不用网页缓存重发全文；
4. 接收全文必须满足以下至少一项：
   - 作者本人提交并明确授权；
   - 原文带 CC BY、CC BY-SA、CC0 等兼容许可；
   - 已确认进入公有领域。
5. 即使允许全文，也应删除姓名、邮箱、申请号、地址、证件、未成年人的可识别信息。

## 5. 维护周期

- 官方要求：申请季每 90 天复核一次；新一轮申请开放后立即复核。
- 案例链接：每 180 天检查可访问性。
- 匿名社区材料：一年后重新评估，若无法补充结果证据则不升级。
- 题目、字数和材料组件必须带路径与年份；禁止把历史题目写成当前固定要求。

## 6. 拆解检查表

阅读一个案例时，只提取这些层面：

1. **主张**：申请者希望招生方记住什么？
2. **证据**：哪些经历、结果或观察支撑该主张？
3. **反思**：经历如何改变选择、方法或理解？
4. **课程匹配**：为什么是这个专业、项目或课程结构？
5. **材料分工**：主文书、活动列表、奖学金文书、作品集是否重复？
6. **可迁移原则**：哪些是结构方法，哪些只是作者独有素材？
7. **风险**：是否戏剧化、空泛、过度归因或依赖陈旧题目？

学习结构，不复制表达。
