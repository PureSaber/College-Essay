# 港新研究生申请文书拆解框架

最后更新：**2026-08-29**

本页用于拆解 SOP、Personal Statement、Research Proposal、Writing Sample 和 MBA essays。它不是可直接替换姓名与专业的模板。

## 1. “高分文书”应怎样理解

港新大学一般不公开研究生文书的单项得分，也很少发布完整录取文书。因此本仓库中的 `quality_score` 只表示一条材料的**策展优先级**：来源是否可靠、要求是否明确、录取结果是否可核验、公开细节是否足够、是否具有教学价值。

它不表示：

- 大学官方给文书打了多少分；
- 获得录取或奖学金的人一定有“顶级文书”；
- 文书可以弥补所有成绩、先修课、研究经历或工作经历缺口；
- 复制成功案例的句式会提高录取概率。

研究生库将材料分为：

| 类型 | 作用 |
|---|---|
| `official_requirement` | 确认项目要求交什么、写什么、多少字 |
| `official_guidance` | 学校或院系对写法、评估重点的解释 |
| `official_exception` | 明确说明不需要、可选或改交其他材料 |
| `admitted_case` | 录取者公开的写作思路、准备过程和结果 |
| `community_case` | 较低证据的经验线索；不能当作当前规则 |

## 2. 五种材料各自负责什么

### SOP / Statement of Purpose

核心问题是：**你准备做什么，为什么现在做，为什么该项目适合完成这一步。**

一个完整的 SOP 通常包含：

1. 当前学术或职业问题；
2. 与该问题相关的学习、项目、研究或工作证据；
3. 从这些经历中形成的具体兴趣或能力缺口；
4. 项目课程、方向、研究群或训练方式如何回应缺口；
5. 合理且可验证的下一步目标。

SOP 不应变成：

- 从小学写起的自传；
- 简历逐条复述；
- 排名、城市和“国际化环境”的赞美；
- 只有长期梦想，没有当前准备；
- 对课程官网的机械抄写。

### Personal Statement

PS 更关注：**你如何形成现在的选择、判断和动机。**

项目若同时要求 SOP 与 PS，可以这样分工：

- SOP：专业目标、学术或职业准备、项目匹配；
- PS：个人路径、关键转折、价值观、背景如何影响选择。

项目只要求一篇 PS 时，仍需保留专业证据，不能只讲情绪和成长故事。

### Research Proposal / Research Plan

研究计划回答：**研究什么、为什么重要、现有研究缺什么、如何做、为什么你和该环境能做。**

最低结构：

1. 暂定题目；
2. 背景与问题边界；
3. 核心研究问题或假设；
4. 关键文献与研究缺口；
5. 数据、材料、方法与可行性；
6. 风险、限制与替代方案；
7. 预期贡献；
8. 时间安排；
9. 与导师、实验室、研究群或地区资源的匹配；
10. 参考文献。

研究计划不是“未来想研究人工智能/金融/文化”的兴趣陈述，也不是硕士论文摘要换一个学校名称。

### Statement of Research Interest / Statement of Intent

它通常短于完整 proposal，重点是：

- 想进入的研究领域；
- 已有研究准备；
- 目前最关心的问题；
- 为什么该院系或导师群适合；
- 未来如何发展。

字数有限时，不必伪装成已经完成的研究计划，但必须具体到问题、对象、方法或文献方向。

### Writing Sample

Writing sample 的任务不是重复“我写作很好”，而是让评审直接观察：

- 能否提出清晰论点；
- 是否正确使用证据和文献；
- 推理是否连贯；
- 是否理解学科方法；
- 是否能处理反例、限制和引用规范。

选择样本时，相关性通常比题目宏大更重要。除非项目允许，不要为了“贴专业”而提交未经指导、匆忙新写的低质量论文。

## 3. 不同路径的推荐结构

### 授课型硕士

推荐逻辑：

> 当前问题或目标 → 已有经历与证据 → 暴露出的能力缺口 → 目标项目的具体训练 → 毕业后的下一步

适合重点呈现：

- 关键课程与定量/写作基础；
- 1–3 段最相关项目或工作；
- 具体技能、决策或结果；
- 为什么现在申请，而不是更早或更晚；
- 目标课程、实践模块或专业方向；
- 可实现的短中期职业用途。

风险：把职业目标写得过大、把课程清单写成官网复制、跨专业只说“兴趣”却不解释补课和迁移能力。

### MPhil / 研究型硕士

推荐逻辑：

> 过去研究或训练 → 识别的问题 → 初步文献位置 → 可执行研究设计 → 导师和方法匹配 → 研究训练目标

适合重点呈现：

- 毕业论文、RA、实验、数据、田野或独立阅读；
- 自己承担的任务，而非项目团队的全部成果；
- 方法技能与仍需训练的部分；
- 为什么 MPhil 是合理阶段，而不是把它写成缩短版 PhD。

### PhD

推荐逻辑：

> 稳定研究问题 → 既往研究形成过程 → 文献与方法准备 → 拟议研究及风险 → 导师/研究群匹配 → 学术发展目标

评审更关心：

- 是否理解研究不确定性；
- 能否把兴趣缩成可研究问题；
- 是否知道现有文献和方法边界；
- 是否有足够证据支撑长期研究；
- 与导师匹配是否具体且非单点依赖；
- proposal 不是承诺最终结论，而是展示研究判断。

### MBA / 专业管理项目

推荐逻辑：

> 职业轨迹与关键选择 → 领导或影响案例 → 当前平台的上限 → 项目带来的能力与网络 → 可行职业转型 → 对同学和社区的贡献

使用 STAR 可以组织案例，但最终要写出：

- 当时如何判断；
- 有哪些权衡；
- 你本人做了什么；
- 结果和反馈；
- 后续行为如何变化。

不要把 MBA essay 写成公司宣传稿或只列管理头衔。

## 4. 证据铺：每个主张都要有支撑

弱表达：

> 我对数据科学很有热情，也擅长解决复杂问题。

更强的结构：

> 在什么项目中处理什么问题 → 使用什么方法 → 发现什么限制 → 做出什么调整 → 得到什么结果 → 因此希望进一步学习什么

建议检查每一段是否包含以下至少两项：

- 明确场景；
- 本人行动；
- 方法或判断；
- 可核验结果；
- 反思；
- 与下一步的因果连接。

只有活动名称、课程名称或公司名称，不等于证据。

## 5. 项目匹配不能只写“学校很好”

有效匹配通常有四层：

1. **能力缺口：** 当前缺什么训练；
2. **具体资源：** 哪门课、哪种方法训练、哪个研究群或实践模块；
3. **使用方式：** 你准备如何利用，而不是只说“感兴趣”；
4. **替代性检验：** 为什么是这个项目，而不是任意排名相近的项目。

研究型申请还要检查：

- 导师当前研究是否真的相关；
- 项目是否要求申请前联糹导师；
- 不要把全部匹配建立在一个可能不招生的教授身上；
- 研究方法、数据或地区资源是否在该院系可获得。

## 6. CV、文书与推荐信的分工

| 材料 | 最适合承担的内容 |
|---|---|
| CV | 时间、角色、课程、技能、项目、成果、发表、奖项等事实 |
| SOP / PS | 选择、因果、反思、目标和项目匹配 |
| Research proposal | 问题、文献、方法、可行性、贡献 |
| Writing sample | 直接展示论䯁和学术写作能力 |
| Recommendation | 第三方观察到的能力、比较基准和研究/工作表现 |

同一经历可以在多份材料中出现，但承担不同任务。不要把 CV 的每一行重新扩写成一段 SOP，也不要让推荐信只是复述申请者自评。

## 7. 高价值自查表

提交前逐项检查：

- 我使用的是目标项目当轮题目，而不是旧年份或别校题目；
- 我知道该材料是必交、可选，还是根本不需要；
- 第一段已经进入具体问题，而不是泛泛的人生格言；
- 每个重要主张都有经历、行动或结果支撑；
- 跨专业申请解释了迁移能力和补足计划；
- 职业目标与过去经历、项目训练和地区机会之间存在因果关系；
- 研究计划包含问题、文献、方法、限制和贡献；
- SOP、proposal、CV 和 writing sample 没有大面积重复；
- 学校名称替换成另一所后，文章不会仍然完全成立；
- 删除了无法证明的夸大、虚构经历和不必要的苦难叙事；
- 字数、语言、文件格式和命名符合申请门户；
- 所有课程、导师和研究群信息在提交前重新核验。

## 8. 使用公开案例的边界

可以学习：

- 信息顺序；
- 证据密度；
- 材料分工；
- 如何解释转专业、研究兴趣或职业转型；
- 如何把项目资源与个人缺口连接。

不应复制：

- 原句、比喻和开头；
- 他人的研究问题；
- 他人的职业目标和家庭经历；
- 不能由自己证明的项目成果；
- 中介或生成式 AI 编造的“个性化细节”。

使用 AI 辅助时，应把它限制在结构检查、语言诊断、重复检测和问题提示。最终事实、判断、研究想法和表达责任仍属于申请者本人。
